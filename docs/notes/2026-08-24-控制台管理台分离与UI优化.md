# UI 全面优化：控制台 / 管理台分离

## 背景

原 DeployLayout 把「项目」与「管理台」放在同一侧栏，模块页按钮过密，流水线仅 6 步且横向挤。

## 改动

1. **信息架构**
   - 控制台：`DeployLayout` → 项目 / 我的申请（管理员另有「进入管理台」）
   - 管理台：`AdminLayout`（深色侧栏）→ `/admin/:tab`，仅平台管理员
2. **模块页**：主操作仅「部署 + 访问链接」，其余收进「更多」菜单
3. **流水线**：11 步纵向时间线 + 进度条（排队→源码→Agent→登录→组→Pod→环境变量→传包→进程→网关→完成）
4. **主题**：冷静工业蓝 token 微调

## 验证

```bash
cd sse-deploy && npm run build
```
