# SSH 跳板引号导致 sudo usage

日期：2026-08-21

## 现象

`sshpass ssh root@跳板 sudo -u sse -H ssh gpu bash -lc '…'` 失败，stderr 为 `usage: sudo`。

## 原因

OpenSSH 远端 `shell -c` 二次转义弄坏嵌套引号，sudo 参数错乱。

## 修复

`sshJump` / `runOnGpu`：命令先 base64，远端 `echo … | base64 -d | bash`，避免引号嵌套。

拷贝新 `dist/` 后重建/重启 `sdpy-api` 即可（无需 no-cache，未改 Dockerfile）。
