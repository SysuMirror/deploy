# sseinfra 面板登录增加用户名

## 背景

student-platform（`:24000`）登录页改为 `username` + `password`（原先仅 password），导致 sdpy-api 的 `SseinfraClient.login()` 无法获得 session。

## 当前 K8s 相关两套凭据

| 用途 | 方式 | 配置项 |
|------|------|--------|
| **面板 API**（建组/部署/MinIO 密钥） | HTTP Cookie + CSRF，`POST /login` | `SSEINFRA_USERNAME` + `SSEINFRA_PASSWORD`（或管理台） |
| **SSH 跳板传包**（scp → gpu → kubectl） | `sshpass ssh root@ssemarket.cn` | `SSEINFRA_SSH_USER` + `SSEINFRA_SSH_HOST`，密码同面板密码 |

跳板→GPU 段仍固定 `sudo -u sse ssh gpu`（集群内约定，与面板账号无关）。

## 改动

- `sseinfra-settings.ts`：`sseinfra_username` / `SSEINFRA_USERNAME`
- `sseinfra-client.ts`：登录表单带 `username`
- 管理台「sseinfra 面板登录」增加「面板账号」
- `configured` = 用户名 + 密码均已配置
- `SseinfraClient.login()` 登录后校验仪表盘 HTML，避免「有 session cookie 但未登录」误判

## 配置

管理台 → 管理员 → sseinfra 面板登录 → 填写用户名、密码 → 测试登录。

或环境变量：`SSEINFRA_USERNAME`、`SSEINFRA_PASSWORD`（兼容 `k8s_username` / `k8s_password`）。
