# 模块多域名 / 子域名 / 自定义域名

## 背景

运维已具备 `*.ssemarket.cn` 证书与泛解析。平台侧落地：模块可配置多个访问域名（平台子域 + 自定义），全局查重，保留根域与 `cloud` 等标签；网关额外生成 Host `server` 块；主域名优先写入 `SDPY_PUBLIC_URL`。灰度 header/query/cookie 字段已入库，路由后续做。

## 改动

| 区域 | 说明 |
|------|------|
| DB | `module_domains` 表，`host` UNIQUE |
| API | `GET/POST /domains`，`PATCH/DELETE /domains/:id` |
| 网关 | `data/nginx/modules.conf`（路径）+ `modules-hosts.conf`（Host server） |
| 前端 | 模块详情「访问域名」 |
| 部署 | `resolvePreferredPublicWebUrl` |

## 公共 nginx 必做

在 **http {}**（与 cloud/sso 并列）增加：

```nginx
include /root/SSE_Market/sse-sdpy/api/data/nginx/modules-hosts.conf;
```

snippet：`deploy/nginx-ssemarket-modules-hosts.conf.snippet`

## 保留

- 根域 `ssemarket.cn` / `www.ssemarket.cn`
- 子域标签：`cloud`、`www`、`sso`、`admin`、`sdpy` 等（见 `RESERVED_SUBDOMAIN_LABELS`）

## 验证

```bash
cd sse-deploy && npm run build
```

部署后：模块绑定 `image` → `https://image.ssemarket.cn`；再部署该环境；curl -Ik https://image.ssemarket.cn

## 现网踩坑（2026-08-24）

`modules-hosts.conf` 已生成且 reload 过，但 `image.ssemarket.cn` 仍出博客，原因不是「没刷新容器」 alone：

1. 公共 nginx 实际用 `-c /etc/nginx/custom.conf`，**不会**自动吃宿主机绝对路径 include
2. 原先只挂了 `modules.conf`→`/etc/nginx/sdpy-modules.conf`（主站 server 内 location），**未挂** Host 文件
3. Host `server{}` 必须在 **http{}**；不能塞进主站 `server{}`

已落地：

- `SSE_market_server/compose.yml`：挂载 `modules-hosts.conf` → `/etc/nginx/sdpy-modules-hosts.conf`
- `nginx_proxy/nginx.conf`：`http{}` 内 `include /etc/nginx/sdpy-modules-hosts.conf;`
- Host 反代头不用 `$connection_upgrade`（conf.d/hosts 加载时机可能早于 map）
