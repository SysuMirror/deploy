# /image/logo.png 404（顶栏 logo 消失）

日期：2026-08-21

## 现象

`https://ssemarket.cn/image/` 顶栏只剩文字「图床」，logo 裂图。`curl -I /image/logo.png` → **404**。

## 原因

1. 前端：`BASE_URL + 'logo.png'` → `/image/logo.png`
2. 公共 nginx：`proxy_pass …/;` **strip** `/image`，上游收到 `/logo.png`
3. Gin 原先只挂 `{prefix}/logo.png`；NoRoute 对 `.png` **直接 404**，不从 `web/dist` 读文件

## 修复（imagebed）

`server/core/static.go`：

- 同时 `StaticFile` `/logo.png` 与 `{prefix}/logo.png`
- NoRoute：静态扩展名先尝试 `dist` 内文件，没有再 404（仍不 SPA 回退）

重打 `imagebed/imagebed-sseinfra.zip`，模块页上传后重新部署正式即可。

## 验证

```bash
curl -sI https://ssemarket.cn/image/logo.png
# 期望 200，Content-Type: image/png
```
