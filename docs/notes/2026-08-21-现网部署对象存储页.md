# 2026-08-21 现网编译部署（对象存储管理页）

## 做了什么

1. 本地 `npm run build`（ui + web + api）
2. 同步到 `ssemarket.cn`：
   - `/root/SSE_Market/sse-sdpy/api/dist`（含 minio-sync / object-storage 路由）
   - `/root/SSE_Market/sse-sdpy/web/`（含对象存储独立页）
3. `cd /root/SSE_Market/sse-sdpy/api && docker compose up -d --build` → 重建并启动 `sdpy-api`
4. 旧版备份：`/root/SSE_Market/sse-sdpy/history/20260821-224919/`

## 验证

- 打开 https://ssemarket.cn/sdpy/ → 模块详情 → **对象存储 → 进入管理**
- 或直达 `/sdpy/modules/<id>/object-storage`
