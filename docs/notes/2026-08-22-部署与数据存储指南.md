# 部署与数据存储指南文档

## 背景

用户要求把部署指南写清楚：宿主机 / Pod / MinIO 三层数据对照、桶申请与访问、凭据与环境变量、管理员 sseinfra 配置等。

## 产出

- 主文档：`docs/SSE-Deploy-部署与数据存储指南.md`
- 同步更新：`iwiki-SSE-Deploy-用户部署指南.md`（v2.1）、`iwiki-SSE-Deploy-对象存储用户手册.md`（v1.1）、`用户部署约定.md` 顶部链接

## 要点摘要

1. 数据三层：MODULE_DATA 宿主机、`/home/cloud/data` PVC、MinIO 桶（桶名=组名）
2. 公网入口 `/sdpy/...`，非 `:23xxx`
3. 桶流程：申请/确保 → 部署 Running → 同步历史 → MINIO_* 注入
4. 平台凭据：SSEINFRA_USERNAME（如 admin）+ PASSWORD + SSH 跳板
5. sdpy 自身：`npm run build` + 覆盖 api/web dist + `docker compose up -d --build`
