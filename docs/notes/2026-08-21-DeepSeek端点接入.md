# 管理台接入 DeepSeek（OpenAI 兼容）

日期：2026-08-21

## 结论

按 [DeepSeek API 文档](https://api-docs.deepseek.com/zh-cn/)：

| 项 | 值 |
|----|-----|
| base_url | `https://api.deepseek.com` |
| format | `openai`（需 API Key） |
| model | `deepseek-v4-flash` 或 `deepseek-v4-pro` |

管理台「AI / DeepSeek / vLLM」提供一键预设；添加后点「设为当前」。支持官方 Tool Calls，可替代坏掉的本地 vLLM tools。

也可 env：`DEEPSEEK_API_KEY` + 默认 `AGENT_FIXER_*`。

## 思考模式 + tools（必做）

按 [思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode)：

- 请求：`thinking: { type: "enabled" }`、`reasoning_effort`
- 响应：`message.reasoning_content`（与 `content` 同级）
- **有 tool_calls 时**：后续所有续轮必须把 assistant 的 `reasoning_content` 原样回传，否则 API **400**

`llm.ts` / `generate-deploy-sh.ts` 已解析并回传；日志会打 `[thinking]` 摘要。
