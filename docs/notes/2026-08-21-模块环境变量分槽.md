# 模块环境变量按 test/prod 分槽

日期：2026-08-21

## 背景

平台基础要求：测试与正式 **数据分开、配置分开**。原先仅有 `MODULE_DATA_ROOT/{模块}/{env}` 数据隔离，缺少按环境的用户环境变量配置。

## 结论

1. 表 `module_env_configs (module_id, env, vars_json)`，`env ∈ {test,prod}`。  
2. 模块页当前环境 Tab → **环境变量** 弹窗：JSON / `.env` 编辑，保存到对应槽。  
3. 部署时：合并用户变量 + 平台键（平台键覆盖）→ 写根目录 `.env`；sseinfra 再 `setEnv`；压缩包路径同时注入 supervisord `environment`。  
4. **一键晋升不复制** 环境变量（配置分槽）。

## 关键

- `module-env-config.ts`
- `routes/modules.ts`：`GET/PUT .../env-config`
- `deploy-worker.ts`：三路径（git/pkg/compose）接入
- `ModuleDetailView.vue`：弹窗

## 未决

- Git 路径主要靠组 `setEnv`；若远端 clone 目录也要落盘 `.env`，需额外 kubectl 写入（暂未做）。
