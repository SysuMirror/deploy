# 详细部署日志 + 镜像补 sshpass

日期：2026-08-21

## 现象

压缩包部署建组成功后，在迁移/传包阶段报「需要安装 sshpass」。  
原因：`sdpy-api` 镜像原先未装 `sshpass`/`openssh-client`，无法走跳板 scp。

## 改动

1. `Dockerfile` 安装 `openssh-client sshpass tar`
2. `sseinfra-pod.ts` / `deploy-worker.ts`：每步详细 log（命令脱敏、跳板、GPU、pod、大小、exit/stderr、堆栈摘要）
3. 迁移数据包几乎为空（&lt;32B）时跳过 scp，避免无意义失败

## 部署

须 **重建 sdpy-api 镜像**（不只 restart），再重试压缩包部署。
