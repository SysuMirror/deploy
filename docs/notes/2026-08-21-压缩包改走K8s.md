# 压缩包改走 K8s（sseinfra）

日期：2026-08-21

## 结论

`DEPLOY_RUNTIME=sseinfra`（默认）时，**压缩包与 Git 都进组容器**，不再默认走本机 docker compose。

## 实现要点

- Worker：`isSseinfraRuntime()` 则统一 `runSseinfraDeploy`；`source=package` → `runSseinfraPackageDeploy`
- 传包：`sseinfra-pod.ts` — sshpass → 集市机 → GPU → `kubectl cp` → supervisord + `deploy.sh`
- 包校验：允许仅 `deploy.sh`；compose 布局仍可上传，但 K8s 部署时必须有 `deploy.sh`
- 本机 compose：仅 `DEPLOY_RUNTIME=compose`

## 运维依赖

生产 deploy-api 所在机需：`sshpass`、`tar`、`scp`，以及能 SSH 到 `SSEINFRA_SSH_HOST`（默认 `ssemarket.cn`）再跳到 `gpu`。密码同 `SSEINFRA_PASSWORD` / `k8s_password`。

## 用户约定

见 `docs/用户部署约定.md`：K8s zip 根目录 `deploy.sh`，监听 `0.0.0.0:$PORT`。
