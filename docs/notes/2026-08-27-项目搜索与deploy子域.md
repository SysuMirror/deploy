# 项目搜索、只读预览与 deploy.ssemarket.cn

> 日期：2026-08-27

## 背景

用户反馈部署台难以「申请加入项目」：公开项目不可见、无搜索。需支持搜索公开项目、只读预览、申请加入；并增加 `deploy.ssemarket.cn` 入口与 OAuth 同 app_id 双回调。

## 已实现

### API

- `GET /api/v1/projects/search?q=` — 搜索 `visibility=public` 项目，返回 `isMember`、`moduleCount`
- `GET /api/v1/projects/:id/preview` — 非成员只读预览（模块名 + 部署状态摘要）
- 原有 `POST /api/v1/projects/:id/join` 不变

### 前端

- 项目页：搜索框 + 预览 / 申请加入
- 项目详情 `?preview=1`：隐藏创建模块、成员管理、模块跳转

### deploy.ssemarket.cn

- 构建：`npm run build:web-deploy` → `apps/deploy-web/dist-deploy/`（`VITE_BASE_PATH=/`，`VITE_API_BASE=/api`）
- nginx 示例：`deploy/nginx-ssemarket-deploy.conf.snippet`
- 打包：`deploy/pack-release.ps1` → `dist-packages/sdpy-YYYYMMDD-HHMMSS/`

### OAuth 双入口（同 app_id）

- deploy-api：按 `Host` / `X-Forwarded-Host` 选 `OAUTH_APP_SECRET` 或 `OAUTH_APP_SECRET_DEPLOY`
- Market OAuth：`oauth2_apps.alt_redirect_uri` / `alt_app_secret`（`sse/SSE_market_server` 已改 authorize + token 校验）
- SQL：`deploy/oauth/credentials/register-oauth-apps.sql`

## 上机步骤

1. **MySQL**（先加列若不存在，再 upsert）  
   ```bash
   docker exec -i sse_market_db mysql -uroot -padmin ssemarket < register-oauth-apps.sql
   ```
2. **Market 后端**（若 alt 列由 AutoMigrate 则 rebuild market server；否则仅 SQL 即可配合新 deploy-api）
3. **覆盖发布包**  
   - `api/` → `/root/SSE_Market/sse-sdpy/api/`  
   - `web/` → `.../web/`（`/sdpy/`）  
   - `web-deploy/` → `.../web-deploy/`（子域根路径）
4. **api `.env`** 增加：  
   `OAUTH_APP_SECRET_DEPLOY`、`OAUTH_REDIRECT_URI_DEPLOY`、`CORS_ORIGIN`
5. `docker compose up -d --build`（sdpy-api）
6. nginx：include `nginx-ssemarket-deploy.conf.snippet`，`nginx -t && reload`

## 验证

- https://ssemarket.cn/sdpy/ → 项目页搜索公开项目 → 预览 → 申请加入
- https://deploy.ssemarket.cn/ → OAuth 登录 → 同上
- `curl -H "Host: deploy.ssemarket.cn" http://127.0.0.1:3002/api/auth/oauth/login-url` → redirectUri 为 deploy 子域
