# sseinfra 建组「超时或失败」

日期：2026-08-21

## 现象

部署日志：`创建 sseinfra 组 sdpy-xxx-p 超时或失败`（Agent 写 deploy.sh 已成功之后）。

## 含义

`ensureGroup`：`POST /add` 后轮询组页约 60–90s，仍判定不存在则抛错。与 Agent/LLM 无关。

## 排查

1. 打开 `http://ssemarket.cn:24000`，看是否有组 `sdpy-image-p`、有无错误闪告  
2. 管理台 → sseinfra「测试登录」  
3. 配额：CPU/内存/存储（默认 2 / 4Gi / 10Gi）是否超限  
4. 可先在面板**手动建同名组**，再在 SDPY 重跑部署

已放宽 `getGroup`（Pending 也算存在），并尽量把面板 flash 带进错误信息；需重建 `sdpy-api`。
