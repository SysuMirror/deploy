# 管理台美化与移动端侧边栏修复

日期：2026-08-21

## 侧边栏点不了（根因）

移动端 `sidebar-backdrop` 的 `z-index: 45` 高于侧栏 `40`，遮罩盖住菜单，点击落在 backdrop 上只会关闭，导航无效。

## 修复

- 侧栏 `z-index: 90`，遮罩 `80`
- 关闭态 `pointer-events: none`，打开态才接收点击
- 菜单项 `min-height: 44px`、`touch-action: manipulation`
- 打开时锁定 `body` 滚动

## 管理台

沿用主站 Azure 蓝 / list-panel / deploy-surface：页眉 kicker、统一 shell Tab、管理员分区卡片（设置 / AI / 管理员）。
