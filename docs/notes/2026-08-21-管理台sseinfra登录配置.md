# 管理台配置 sseinfra 面板登录

日期：2026-08-21

## 结论

管理员可在 **管理台 → 管理员 → sseinfra 面板登录** 填写地址/密码并「测试登录」。  
运行时读取：`env`（锁定）> `platform_settings` > 默认。

## API

- `GET/POST /api/v1/admin/settings/sseinfra`
- `POST /api/v1/admin/settings/sseinfra/test-login`

密码不回传明文，仅 `maskedPassword` / `configured` / `passwordEnvLocked`。
