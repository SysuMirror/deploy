# 对象存储：历史数据同步与桶生命周期

日期：2026-08-21

## 需求

1. 部署平台提供按钮，将模块历史数据同步到对应 MinIO 桶。  
2. 桶不要随便删：生命周期伴随模块，**删 K8s 组 / 删模块默认不删桶**。  
3. 可在部署平台查看/管理绑定状态。

## 实现

### 数据绑定

表 `module_object_storage`（`module_id` + `env`）：桶名、密钥标签、状态（`provisioned` / `synced` / `orphaned`）、上次同步统计。删模块时标记 `orphaned`，记录保留便于审计。

### API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/v1/modules/:id/object-storage?env=` | 当前环境状态 + 宿主机数据量 |
| POST | `/v1/modules/:id/object-storage/ensure` | 幂等建桶+发密钥（不删桶） |
| POST | `/v1/modules/:id/object-storage/sync` | 推 MODULE_DATA → Pod → 上传桶 |
| GET | `/v1/admin/object-storage` | 管理台绑定一览 |

平台**不实现**删桶 API。

### 同步流程

1. `ensure` 桶（名=组名，标签=组名）。  
2. 组须 Running。  
3. 默认将宿主机 `{MODULE_DATA}/{模块}/{env}` 同步进 Pod `/home/cloud/data`。  
4. 从 WZ8 `minio_keys.json` 取密钥（不写日志），写入组 `MINIO_*`。  
5. Pod 内 `pip install minio` + `fput_object`；跳过 `.db` / JWT 等。  
6. 审计 `sseinfra.minio.sync`。

### UI

- 模块详情：区块 **「对象存储（MinIO）」→「进入管理」**，或环境栏 **「对象存储」**。
- 独立页：`/modules/:moduleId/object-storage?env=prod|test`（开通 / 确保 / 同步 / 日志）。
- 管理台「系统」：绑定列表与策略说明。

## 验证

1. 审批通过或点「确保对象存储桶」后，绑定状态为 `provisioned`。  
2. 组 Running 后点「同步历史数据到桶」，状态变 `synced`，桶内可见 `images/` 等 key。  
3. 释放组后桶仍在；删模块后绑定为 `orphaned`，桶仍在。

## 未决

- 若 `minio_keys.json` 路径变更，需更新 `loadMinioCredsForLabel` 探测逻辑。  
- 超大目录同步耗时长，依赖现有 scp/exec 超时配置。
