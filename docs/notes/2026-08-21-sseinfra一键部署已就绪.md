## 新增面板能力（相对 08-19）

导航：总览 / 主机 / 审计 / **编排** / **共享** / **存储** / **数据库**

| 路径 | 作用 |
|------|------|
| `/storage` | MinIO：ensure、建桶、发密钥（桶级隔离） |
| `/databases` | MySQL / Redis / Qdrant：ensure、按组发凭证 |
| `/shared` | 教师上传；pod 只读挂 `/shared` |
| `/group/<name>` | 环境变量；**服务部署**（repo/branch/subdir/mode/token） |
| `/harness` | Agent 编排（与一键部署正交，可后做） |

组页部署相关路由（仍为 Cookie+CSRF 表单，非 JSON API）：

- `POST /group/<name>/deploy/add`
- `POST .../deploy/<did>/run|stop|delete`
- `GET  .../deploy/<did>/status|logs`
- `POST /group/<name>/env/set|delete`

自动注入给 `deploy.sh` 的环境（标签=组名的凭证才会挂上）要点：

- `PORT=8080`
- `MINIO_ENDPOINT` / `MINIO_ACCESS_KEY` / `MINIO_SECRET` / `MINIO_BUCKET`
- `MYSQL_*` / `REDIS_*`（若已发对应凭证）

代码：`/opt/student-platform/web/deploys.py`、`minio_svc.py`、`db_svc.py`。

当前示例组：`qwen`（GPU），公网 Web `ssemarket.cn:23001`。

## 开工建议（最小闭环）

1. **示例仓**：`frontend/` + `backend/` + 根目录 `deploy.sh`（装依赖、起前后端或反代、读 MinIO env）
2. **教师侧一次**：`/storage` 建桶 → 发密钥（标签=组名）→ 可选 `/databases` 发库凭证
3. **组页**：粘贴仓库 URL → 添加 → 跑起来 → 打开 `:23001`
4. **SDPY**：本期可不改；或仅做「文档/跳转/流水线记录」。JSON API 封装可后置

### 注意

- **表单 URL 就是可调用的 HTTP 接口**（见下节），不是另一套隐藏 API
- 私有仓：表单仍要填 token（尚未做到 iWiki 那种「仅管理员平台凭证、用户零 token」；公有仓可留空）
- 大文件放 MinIO 或 `/shared`，不要塞满 PVC
- 应用必须监听 `0.0.0.0`，不是 `127.0.0.1`

## 表单即接口（源码确认）

机器：WZ8 `/opt/student-platform/web/app.py`。点击按钮 = 调对应 path；写操作读 `request.form`，返回 **302 + flash**；查状态已是 JSON。

| 操作 | 方法 | Path | 入参 | 返回 |
|------|------|------|------|------|
| 添加部署 | POST | `/group/<name>/deploy/add` | `csrf_token,repo,name?,branch?,subdir?,mode?,token?` | 302 |
| 执行部署 | POST | `/group/<name>/deploy/<did>/run` | `csrf_token` | 302 |
| 停止 / 删除 | POST | `.../stop`、`.../delete` | `csrf_token` | 302 |
| 状态 | GET | `.../status` | Cookie | **JSON** (`jsonify`) |
| 日志 | GET | `.../logs` | Cookie | **text/plain** |
| 环境变量 | POST | `/group/<name>/env/set` | `csrf_token,key,value` | 302 |

鉴权：`POST /login` → session Cookie。  
CSRF：表单字段 **或** 头 `X-CSRF-Token`（`csrf_protect` 已支持）。

流水线可直接调这些 path；写操作容忍 302 即可。
