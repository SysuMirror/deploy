# 按环境下载 MODULE_DATA 压缩包

日期：2026-08-21

## 结论

模块页当前环境 Tab → **下载数据**：打包宿主机 `{MODULE_DATA_ROOT}/{模块}/{test|prod}` 为 zip。

- `GET /v1/modules/:id/data-export?env=` 预检  
- `GET /v1/modules/:id/data-export.zip?env=` 下载  
- 上限默认 512MB（`MODULE_DATA_EXPORT_MAX_MB`）

## 注意

仅宿主机 MODULE_DATA；纯 K8s 且宿主机已清空时需另备份 Pod。
