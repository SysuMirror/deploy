# 失败自动释放组 + 每次重新部署从头建组

日期：2026-08-21

## 行为

1. **每次部署**：先 `deleteGroup`（若存在）再 `ensureGroup`，流水线从「创建组」走起。  
2. **失败 / 取消**：自动再 `deleteGroup` 释放容器，清空该环境 active URL，并写审计。  
3. **成功**：保留组。

实现：`deploy-worker.ts` 的 `recreateSseinfraGroup` / `releaseSseinfraGroupAfterFail`。

## 注意

重部署会删旧 Pod/PVC（组级数据随之释放）。业务数据应放模块 `MODULE_DATA` 或外部库，不要只靠组内盘。
