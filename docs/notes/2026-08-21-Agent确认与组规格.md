# Agent 确认后生成 + 组默认规格

日期：2026-08-21

## Agent 流程

1. 部署/迁移压缩包缺 `deploy.sh` → API **409** `NEED_AGENT_DEPLOY_SH`  
2. 前端弹窗提醒，用户确认或取消  
3. 确认后 `confirmAgentGenerate=true` 入队；worker 内 Agent 生成（可 `cancel`）  
4. 部署中 compose Agent 自愈：仍靠勾选，不另弹窗  

## 组资源默认（每环境一组）

| 项 | 默认 | 调配 |
|----|------|------|
| CPU | `2` | 管理台 sseinfra / `SSEINFRA_DEFAULT_CPU` |
| 内存 | `4Gi` | `SSEINFRA_DEFAULT_MEM` |
| 存储 | `10`（Gi） | `SSEINFRA_DEFAULT_STORAGE` |

仅影响 **新建组**；test/prod 各一独立组。已有组在 sseinfra 面板改。
