## 现网注意

1. 公共 nginx 须 `include` 平台的 `modules.conf`
2. `GATEWAY_RELOAD_CMD` 应对准真正挂了该 conf 的 nginx（例：`docker exec … nginx -s reload`）；默认容器内 `nginx -s reload` 往往无效
3. `GATEWAY_UPSTREAM_HOST`：frp 在宿主机时，宿主机 nginx 用 `127.0.0.1`；网关在容器内用 `host.docker.internal`
4. 已成功但 URL 仍是 `:23xxx` 的模块需再部署一次以刷新 slot + conf
