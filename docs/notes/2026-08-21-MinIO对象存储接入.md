# sseinfra MinIO 对象存储接入（图床 + SDPY 申请桶）

日期：2026-08-21

## 探查结论（像文件夹吗？）

[sseinfra `/storage`](http://ssemarket.cn:24000/storage) 是 **MinIO（S3 兼容）**，不是把桶挂成 Linux 目录。

| 说法 | 实际 |
|------|------|
| 「像文件夹」 | 对象 **key** 可用斜杠前缀，如 `images/2026/08/21/a.png`，SDK `list_objects(prefix=…)` 看起来像目录 |
| 真目录挂载 | 仅 **`/shared`**（教师只读共享）；与 MinIO 不同 |
| Pod 内端点 | `http://minio.platform-infra.svc.cluster.local:9000`（集群内网） |
| 自动注入 | 密钥 **label = 组名** 时，`deploy.sh` 收到 `MINIO_ENDPOINT` / `ACCESS_KEY` / `SECRET` / `BUCKET` |

面板：建桶 `POST /storage/bucket/add`；发密钥 `POST /storage/key/add`（label、bucket、perm）。

## 代码改动

### imagebed

- `blob.Store`：有完整 `MINIO_*` → MinIO；否则仍写 `DATA_DIR`
- 原图/缩略图走 Store；SQLite + JWT 仍在 PVC/`DATA_DIR`
- `/i/` 从 Store 流式读出（不再依赖本地盘路径）

### SDPY

- 模块页 **「申请对象存储」** → 申请类型 `minio_bucket`
- 平台管理员审批通过 → 自动建桶（名=组名）+ 发读写密钥（标签=组名）
- `SseinfraClient.provisionModuleObjectStorage`

## 使用流程

1. 模块页当前环境点「申请对象存储」
2. 管理台审批通过（须已配置 sseinfra 面板密码）
3. **重新部署**该环境（注入 `MINIO_*`）
4. 新上传图片进桶；旧 PVC 图需另迁（可后续脚本）

也可教师在面板手动：建桶 → 发密钥（标签=`sdpy-image-p`）→ 重部署。

## 验证

- 组内日志：`二进制存储后端: minio:sdpy-…`
- 上传一张图后，用面板示例或 SDK `list_objects` 能看到 `images/…`
