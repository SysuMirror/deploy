# 迁移/重试不再先删线上组

日期：2026-08-21

## 原因

此前「每次先 deleteGroup 再部署 + 失败再释放」：迁移一开始就把旧组删了；sshpass 失败后又删新组 → 线上直接没了。

## 新行为

| 情况 | 行为 |
|------|------|
| 组已存在 | **复用**，失败/取消**不删** |
| 组不存在（本次新建） | 失败/取消才自动释放 |
| 强制重建 | env `SSEINFRA_FORCE_RECREATE=1` |

## 已挂掉的服务

需重新点一次「部署正式/测试」（现在镜像已有 sshpass），或在面板手动重建同名组后再部署。
