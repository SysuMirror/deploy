# 删除模块时释放 K8s 组

日期：2026-08-21

## 结论

`deleteModule` / `deleteProject` → `teardownModuleRuntime` 在停本机 compose 之后，对测试/正式组名调用 sseinfra `POST /group/<name>/delete`，释放 Pod / PVC / frp。

## 行为

- 组不存在：跳过
- 曾部署过 `infra*` 或当前 `DEPLOY_RUNTIME=sseinfra`：必须能登录面板；无密码则删除失败并提示
- 释放失败：整次删除中止（避免库删了组还在）

## 关键

- `SseinfraClient.deleteGroup`
- `project.ts` → `releaseSseinfraGroups`
