# 为什么 iwiki.ssemarket.cn 挂不上去

日期：2026-08-24

## 结论

iWiki **独立部署**，不走 SSE Deploy 的 `module_domains`。`iwiki` 在 sdpy 侧为**保留子域标签**（防与用户模块冲突），与 iWiki 自建子域不冲突。

子域挂载见 iWiki 仓库 note：`iwiki/docs/notes/2026-08-24-双入口路径与子域.md`（nginx Host server + 运行时 base 检测）。

## 证据

### 1. 保留标签拦截

`sse-deploy/apps/deploy-api/src/services/module-domains.ts`：

```ts
export const RESERVED_SUBDOMAIN_LABELS = new Set([
  'cloud', 'www', 'sso', 'mail', 'ftp', 'api', 'admin', 'monitor',
  'jaeger', 'sdpy', 'iwiki', 'ns1', ...
]);
```

- `assertHostAllowed`：`kind=subdomain` 标签命中保留 → 报「子域名「iwiki」为平台保留，不可占用」
- `kind=custom` 填 `iwiki.ssemarket.cn` 同样不行：`*.ssemarket.cn` 的单级子域强制走 subdomain 类型（见 174–180 行）

### 2. iWiki 不在平台 modules 表

- `listEnabledDomainsForGateway()` 是 `module_domains JOIN modules`，取 `active_prod_web_port` 作为 upstreamPort
- iWiki 现网是**独立部署**：`iwiki/deploy/split` 的 compose（容器 `iwiki-api-api-1`），走 `ssemarket.cn/iwiki/` 路径，**不是 sdpy 模块**
- 无域名记录 → `modules-hosts.conf` 里直接 `# skip … 尚未部署`，不会生成 `iwiki.ssemarket.cn` 的 server{}

对比：image.ssemarket.cn 能通，是因为 imagebed 注册成了 sdpy 模块 `image` 并经平台部署（有 `active_prod_web_port`），且现网 nginx 已 include `modules-hosts.conf`（`SSE_market_server/compose.yml` + `nginx_proxy/nginx.conf`，见 `2026-08-24-模块多域名与子域名.md`）。

## 要挂上 iwiki.ssemarket.cn 的三条路径

### A. 接入 sdpy 平台（正规）
1. 把 `iwiki` 从 `RESERVED_SUBDOMAIN_LABELS` 移除（`module-domains.ts`；`modules.ts` 的 `reservedSubdomains` 从同一 Set 读，改一处即可）
2. 重新构建部署 sdpy-api，`regenerateNginxRoutes` 重写 `modules-hosts.conf`
3. 平台注册模块（模块名 `iwiki` 不在 `RESERVED_MODULE_NAMES`，可用）、按 sdpy 流程部署 iWiki
4. 模块详情「访问域名」添加 `subdomain=iwiki`，重新部署该环境 → 生成 Host server{} 并反代到上游端口

### B. 不接平台，手动在公共 nginx 加 Host server
在 `nginx_proxy/nginx.conf` 的 http{}（与 cloud/sso、modules-hosts include 并列）手动加：

```nginx
server {
  listen 443 ssl;
  server_name iwiki.ssemarket.cn;
  ssl_certificate     /etc/letsencrypt/live/ssemarket.cn/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/ssemarket.cn/privkey.pem;
  client_max_body_size 200m;
  location / {
    proxy_pass http://127.0.0.1:<iwiki-web端口>;
    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

### 无论哪条，iWiki 应用自身还要适配
- `OAUTH_REDIRECT_URI`：现在是 `https://ssemarket.cn/iwiki/oauth/callback`，子域下要 `https://iwiki.ssemarket.cn/oauth/callback`（OAuth 控制台同步登记）
- 前端构建 base：`VITE_BASE_PATH` 当前 `/iwiki` → 子域下应为 `/`
- `VITE_API_BASE`：子域下指向 `https://iwiki.ssemarket.cn/iwiki-api`（或同域 `/api` 反代）

## 未决
