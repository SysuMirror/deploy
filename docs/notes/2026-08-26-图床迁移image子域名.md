# 图床迁移到 image.ssemarket.cn

> 日期：2026-08-26  
> 产物：`基础服务/imagebed/imagebed-sseinfra.zip`

## 结论

图床主入口改为 **https://image.ssemarket.cn/**（前端 + API 同源单端口）。路径 `/sdpy/image/`、`/image/` 可保留备用。

## 代码改动

| 项 | 说明 |
|----|------|
| `deploy.sh` | 检测 `SDPY_PUBLIC_URL` 为子域名根 → `VITE_BASE_PATH=/`、同源 API、`PUBLIC_BASE` 用子域名 |
| `config.go` | 子域名优先作 `PublicBaseURL`；清空 `PathPrefix` |
| `config.yaml` | `public_base_url` / OAuth `redirect_uri` → `image.ssemarket.cn` |
| `pack-sseinfra.ps1` | 默认打包 `base=/`、同源 API |
| 前端 favicon/logo、skills、文档 | URL 全面切到子域名 |

## 上线步骤

1. SDPY 模块 `image` → **访问域名** → 正式：子域标签 `image`、用途=前端、设为主  
2. 模块环境变量：`IMAGEBED_OAUTH_REDIRECT_URI=https://image.ssemarket.cn/oauth/callback`（及 APP_ID/SECRET）  
3. 集市 OAuth 控制台登记同上回调  
4. 上传 `imagebed-sseinfra.zip` 并部署正式环境  
5. 验收：`https://image.ssemarket.cn/` 登录；上传图直链含 `image.ssemarket.cn/i/`

## 打包

```powershell
cd 基础服务/imagebed
powershell -ExecutionPolicy Bypass -File .\deploy\pack-sseinfra.ps1
```
