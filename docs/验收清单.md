# SSE Deploy 验收清单（初版）

验收时请在本机或服务器（**需已安装 Docker**）按下列项勾选。

## A. 本地控制台

- [ ] `cd sse-deploy && npm run dev:api` → `http://localhost:3002/api/health` 返回 ok  
- [ ] `npm run dev:web` → 打开 `http://localhost:5174`  
- [ ] OAuth 可登录（需配置真实 `OAUTH_*`；本地冒烟可用脚本绕过，见下）

## B. 模块与上传

- [ ] 创建项目、注册模块名（保留字如 `projects` 应被拒绝）  
- [ ] 上传 zip：须含 `frontend/`、`backend/`、`compose.yml`  
- [ ] 示例包目录：`deploy/examples/sample-app/`（可整目录打成 zip 上传）  
- [ ] 模块详情展示测试/正式的前端与后端 URL（含 `-api`）

## C. 部署（需 Docker）

- [ ] 「部署测试」成功后，本机可访问 `127.0.0.1:{webPort}` / `{apiPort}`  
- [ ] `data/nginx/modules.conf` 出现对应 `location /sdpy/test/{name}/`  
- [ ] 「部署正式」不停止测试容器（独立 compose 项目 `sdpy-test-*` / `sdpy-prod-*`）  
- [ ] 可选勾选 `--no-cache` 可触发无缓存构建

## D. 生产路径（服务器）

- [ ] 公共 nginx 仅加入 `deploy/nginx-ssemarket-sdpy.conf.snippet`（无逐模块 location）  
- [ ] `https://ssemarket.cn/sdpy/` 打开管理站  
- [ ] `https://ssemarket.cn/sdpy/test/{name}/` 与 `-api` 可访问  
- [ ] 前端构建使用 `SDPY_API_PUBLIC_URL`（见《用户部署约定》）

## E. 本机无 Docker 时的自测结果（开发机已跑）

| 项 | 结果 |
|----|------|
| API health | 通过 |
| 保留字校验 | 通过 |
| 模块创建 + URL 规则 | 通过 |
| zip 上传与 compose 校验 | 通过 |
| 部署排队 + 清晰失败提示 | 通过（提示需安装 Docker） |
| 真实容器拉起 | **阻塞：当前开发机无 docker 命令** |

复跑冒烟（API 已启动时）：

```bash
cd apps/deploy-api
node scripts/smoke-local.mjs
```
