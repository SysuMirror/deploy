# 灰度发布设计（历史说明）

> **初版状态**：简化版已改为「测试 / 正式各自独立 `docker compose` 部署」，不再使用 Header 灰度与镜像晋升。请以 [`用户部署约定.md`](./用户部署约定.md) 为准。

## 旧模型（已弱化）

| 槽位 | 访问 URL（旧） |
|------|----------------|
| test | `https://{baseDomain}/test/{module}` |
| prod | `https://{module}.{baseDomain}` |

曾支持在正式域名带灰度 Header 切到测试容器（旧名 SoftLab，现为 SSE）。

## 当前模型

| 槽位 | 前端 | 后端 |
|------|------|------|
| test | `/sdpy/test/{module}/` | `/sdpy/test/{module}-api/` |
| prod | `/sdpy/{module}/` | `/sdpy/{module}-api/` |

路由由平台网关 `data/nginx/modules.conf` 管理，公共 nginx 不写逐模块 location。
