## 1. 产品定位（当前）

SSE Deploy（sdpy）：**上传 zip → Docker Compose 一键部署测试/正式 → 固定路径反代访问** 的轻量云部署平台。

目标用户：实训 / 课程项目组，需要快速把前后端挂到学院域名路径下联调。

---

| Market OAuth 登录 | 生产 / 本地双应用 |
